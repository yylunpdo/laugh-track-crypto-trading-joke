A make.fun bounty entry: one line, under 200 characters, about crypto and trading life.

## The joke

> I bought the dip, the dip bought a shovel, and now I'm HODLing a hole the chart calls a long-term investment.

## How it works

`main.py` (Python standard library only, fully deterministic) writes that single
line to `/output/entry.txt`. No network, no dependencies, no randomness — the
same line is produced on every run.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
